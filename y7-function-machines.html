What is a function machine?

A function machine takes an input, follows a rule, and gives an output.

Think of it as a number going in one side and a new number coming out the other. The rule is written inside the machine.

Input5
→
Rule× 3
→
Output15

Key vocabulary

  • Input — the number you put into the machine.
  • Output — the number that comes out.
  • Function machine — a diagram that shows a rule applied to a number.
  • Inverse operation — the operation that undoes another (e.g. + undoes −, × undoes ÷).
Today you will find outputs from inputs forwards, then work backwards to find inputs from outputs. You will meet one-step and two-step machines.

Step 1

Apply × 2 to the input: 7 × 2 = 14. This is the middle value.

Step 2

Apply + 5 to 14: 14 + 5 = 19. So the output is 19.

Check

Input 7 → ×2 → 14 → +5 → 19. Always finish both steps before writing the output.

Letters and numbers

A letter can stand for the input. If the rule is 2x + 3 and the input is 4, then x = 4, so 2 × 4 + 3 = 11.

Substitute to find a value, find the output of a letter rule, or work backwards to find the input. Use positive whole numbers.
